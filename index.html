Shorts Studio

운영자가 자기 YouTube 채널을 관리할 때 사용하는 Windows 도구입니다.

무엇을 하나요?

Google에서 이미 승인한 채널의 연결과 영상 상태를 확인합니다. 운영자가 게시 작업을 요청했을 때는 YouTube API Services를 통해 영상과 게시 정보를 전송할 수 있습니다.

어떻게 연결하나요?

운영자가 로컬 도구에서 시작해 Google에 로그인하고 연결할 채널을 선택합니다. 이 웹사이트는 앱을 설명하는 문서로, 로그인이나 영상 업로드를 받지 않습니다.

어떤 정보를 사용하고 어떻게 접근을 철회하는지는 개인정보처리방침에서 확인할 수 있습니다.
