개인정보처리방침

2026년 11월 14일 기준

Shorts Studio는 YouTube API Services를 사용합니다. Google의 정보 처리 방식은 Google 개인정보처리방침에서 확인할 수 있습니다.

접근하는 정보와 사용 목적

Google에서 채널 접근을 승인하면, 도구는 채널 이름과 식별자 등 채널 정보로 연결 대상을 확인합니다. 채널 관리에 필요한 경우 영상의 제목, 설명, 게시 및 처리 상태, 재생목록과 댓글을 확인합니다. 운영자가 요청한 게시 작업에는 영상 파일과 썸네일, 제목·설명 등 게시 설정, 선택한 댓글이나 재생목록 정보가 포함될 수 있습니다. 도구는 요청된 작업을 위해 해당 정보를 Google 또는 YouTube에 전송합니다.

저장, 공유 및 보호

Google이 발급한 연결 정보는 채널별로 운영자의 Windows 컴퓨터에 저장됩니다. 이 정보는 승인된 연결을 유지하는 데 사용합니다. 처리 결과 확인과 중복 작업 방지를 위해 영상이나 댓글의 식별자, 처리 상태, 작업 기록을 로컬에 남길 수 있습니다. 운영자가 준비한 원본 영상과 게시용 문구도 로컬 작업 파일에 남을 수 있습니다. 이런 파일과 앱 연결 정보는 이 안내 사이트로 전송되지 않습니다. Shorts Studio는 Google에서 받은 사용자 데이터를 판매하거나 광고에 사용하지 않습니다. Google에서 받은 정보의 사용 및 전송에는 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건이 적용됩니다.

보관, 접근 철회 및 삭제

연결 정보는 활성 연결을 유지하는 데 사용합니다. 작업 기록은 요청한 작업을 확인하거나 중복 처리를 방지하는 데 필요한 범위에서 보관합니다. 승인 철회와 데이터 삭제는 별개입니다. Google 계정의 앱 접근 설정에서 다음 접근을 차단할 수 있습니다. Windows에 저장된 연결 정보와 관련 Google 사용자 데이터의 삭제 요청이나 개인정보 문의는 luke.w.heo@gmail.com으로 보내 주세요. YouTube에 이미 게시한 콘텐츠는 별도로 YouTube에서 관리할 수 있습니다. 비밀번호나 인증 코드는 이메일에 넣지 마세요.
